Gen1Recomp 3DS - building your SD card folder

Put this folder next to the gen1recomp desktop app (the one you play on the
PC).  Then:

  1. Drop your own Game Boy ROM files (.gb / .gbc) into the "roms" folder
     here -- or import them in the desktop app as usual, either works.
  2. Double-click the file for your system:
        Windows   Export-3DS.bat
        macOS     Export-3DS.command
        Linux     Export-3DS.sh
     It asks nothing and prints where it saved everything.
  3. Copy the "3ds" folder it creates in "sd-card" onto the root of your SD
     card, merging with the folder already there.
  4. Put the card back in the console and start Gen1Recomp.

No ROMs are included or downloaded.  Only cartridges you dump yourself.
